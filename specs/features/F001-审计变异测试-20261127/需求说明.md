# 审计变异测试 — 功能需求说明书

## 1. 背景与价值

**为什么做**：`tools/skill-audit.ps1` 抓到过 21 处真实缺陷，但它对**人造缺陷**的捕获率从未验证过——门禁没抓过植入物 = 未验证的门禁。上一轮深化的全部证据是纸面自洽，本需求是深化任务书 Phase 1 的第一交付物，同时充当 Phase 0 试交付的载体。

**做成什么样**：一条命令完成「植入四类已知缺陷 → 审计逐项报告 → 自动还原 → 捕获率门禁判定」，让任何人可以一键证明审计门禁没有静默失明。

**关联**：tools/skill-audit-findings-20261127.md（上轮审计证据）；深化任务书 Phase 0 / Phase 1。

## 2. 范围

### 本次做

- 变异测试模式全链路：植入 → 逐项报告 → 还原 → 捕获率汇总判定（AC-001 / AC-002 / AC-003）

- 自由文本语义矛盾检测 — 研究性问题，本次只做其最简机械可判定形态（双定义声明）

## 4. 需求详述

### 4.1 核心流程

> 主线路径的全局视角；每个节点的细节由 AC 承载。

1. **准备**：确认基线（普通审计 CLEAN + git 工作区干净），不满足则拒绝开始
2. **植入**：四类缺陷（断链 § 引用 / assets 路径改名 / 重复规范句双定义 / spec 单数路径（缺 s 前缀））每类 ≥2 处、总计 ≥10 处，植入位置来自固定清单、可复现
3. **审计**：运行审计，植入缺陷应逐一出现在报告对应检查节（文件:行号）
4. **还原**：按植入清单逐文件还原（git 优先）
5. **判定**：打印「捕获 X / 植入 N」汇总行；X < N ⇒ FAIL；有未还原残留 ⇒ 非零退出并列清单

### 4.2 交互规则

- 变异测试经独立命令（`tools/skill-mutate.ps1`）进入；`tools/skill-audit.ps1` **零参数 = 普通模式**，行为与现状一致（CR-001：入口形态由设计定为独立命令）
- 每次变异运行结束必须打印汇总行（捕获 X / 植入 N），不得只给零散 FINDINGS
- 中断后重跑：必须识别未还原残留并报告，不得当作干净基线

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 捕获率门禁：X < N ⇒ 整体 FAIL（非零退出码），禁止静默报成功 |
| BR-002 | 零残留：任何退出路径下库不得静默留在被污染状态；崩溃/中断必须报告未还原清单 |
| BR-003 | 回归保护：普通模式（零参数）的**既有检查项判定语义、既有报告节结构与内容、退出码语义**不变；新增检查项独立成节（CR-001） |

## 5. 验收标准

> AC 是这份文档的核心交付物。技术方案、任务拆分、TDD 测试用例全部从这里派生。

### 5.1 正常流程 (Happy Path)

- [x] **AC-001**: 四类缺陷全数逐一报告
  - **Given** skill 库处于复跑 CLEAN 状态
  - **When** 以变异测试模式运行审计
  - **Then** 四类植入缺陷（每类 ≥2 处、总计 ≥10 处）逐一出现在报告对应检查节且可按 文件:行号 定位，整体判定 FINDINGS

- [x] **AC-002**: 还原后回到干净基线
  - **Given** 变异测试已产生报告
  - **When** 执行还原
  - **Then** git 工作区无残留改动，且再次普通审计为 CLEAN

### 5.2 边界与异常 (Edge & Error Cases)

- [x] **AC-003**: 盲区显式失败 ← BR-001
  - **Given** 某植入缺陷超出当前审计规则覆盖范围
  - **When** 变异测试结束
  - **Then** 汇总明确显示「捕获 X / 植入 N」；X < N 时整体判 FAIL（非零退出码），禁止静默报成功

- [x] **AC-004**: 崩溃不留下静默污染 ← BR-002
  - **Given** 变异过程被中断而有植入物未还原
  - **When** 脚本终止
  - **Then** 非零退出码 + 未还原文件清单；不允许留下被污染却显示成功的库

### 5.3 业务规则验证 (Business Rules)

- [x] **AC-005**: 普通模式契约不变 ← BR-003
  - **Given** 用户零参数运行
  - **When** 审计完成
  - **Then** 既有检查项的判定语义、既有报告节的结构与内容、退出码语义与引入变异能力之前完全一致；新增检查项（双定义检测）独立成节，不影响既有部分（CR-001 修正口径）
